## 시험 준비 팁
- 컴퓨팅/스토리지/네트워킹 핵심 서비스(EC2, Lambda, S3, VPC, RDS, DynamoDB)를 우선 정리하세요.
- IAM 정책 평가 로직(명시적 거부 우선), 역할 위임, 교차 계정 액세스를 확실히 익히세요.
- Well-Architected Framework(특히 운영 우수성/보안/신뢰성) 관점으로 시나리오를 연습하세요.
- 무료 티어 또는 샌드박스 계정으로 CI/CD 파이프라인을 직접 구축해 보세요.
- 공식 문서/화이트페이퍼를 기준으로 개념을 정리하세요.
